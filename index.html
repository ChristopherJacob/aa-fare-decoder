Quick reference

AA booking classes

AA’s published earning chart groups F/J as full-fare First/Business; A/C/D/I/R as discounted First/Business; W/P as Premium Economy; Y/H/K/M/L/V/G/S/N/Q/O as Economy; and B as Basic Economy. Actual fare rules still control.

How to read it

Booking class vs. fare basis

Booking class is usually one letter and identifies the inventory bucket/cabin. A fare basis is a longer airline-defined code that starts with the booking class and can encode pricing or fare-rule information.

Suffixes are not globally standardized. This decoder separates AA-published positional rules from common industry conventions and historical AA patterns. Each result is tagged so you can see what is confirmed versus inferred.

AA-specific decoding

What we can reliably infer

Character 1Booking class / fare class. AA defines this as the first character of the ticketed fare basis.
Character 7 = BAA-published Basic Economy identifier. AA also identifies Basic Economy with fare-type codes EOU or ERU.
Character 8For AA's 2023 U.S. Domestic and Mexico/Caribbean/Latin America filing construct, this can encode sales-channel/viewership. Numeric = standard third-party; Z/Y/X/W/V/U/T/S/Q/R = third-party modern retailing Value; A/B/D/E/G/J/K/M/N/P = American-owned.

The position-8 construct was introduced for specific AA markets and filing architecture; it should not be assumed to describe every historical, international, private, negotiated, or partner fare.
